# My Budget Deal 99

A simple static website for My Budget Deal 99.

## Free GitHub Pages deployment

1. Create a public GitHub repository, for example `mybudgetdeal99.github.io` if your GitHub username is `mybudgetdeal99`.
2. Upload `index.html` and `logo.png`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will be available at your GitHub Pages URL.

GitHub Pages hosts static HTML/CSS/JS sites for free on GitHub Free public repositories.

## Before Amazon Associates submission

Replace the placeholder YouTube URL with your exact public YouTube channel URL.

Also add your exact public Instagram/YouTube URLs to the Amazon Associates application.

Important: Amazon evaluates the actual sites you submit and looks for original, recent content. A one-page landing site is a starting point, not a guarantee of approval. Build out original product guides/reviews and keep the site updated.

The site intentionally does not use Amazon logos, Amazon customer reviews, or copied Amazon product content.
